# 拾菌记 MycoTrail — 第七版：安全与可靠性（2026-11-01）

**更安全的物种资料**
- 每种菌的详情页新增“分级 / 资料审核 / 中毒表现 / 注意”。审核状态如实标注：已核对资料、待核实或资料有分歧。这些都是编辑对照外部资料做的核对，**不是真菌学专家审核**。
- 史密斯鹅膏改为“致命”（会导致肾衰竭）。
- 卷边桩菇（有毒，致命）和卷缘齿菌（羊蹄菇，可食）名字很像，两个页面都加了提醒。
- 只有一份资料支持的食用菌会标“待核实”，不再出现在今日一菌、本月推荐和食谱里。

**食谱**
- 每道食谱都只写具体的菌名，不再有“任何菌”“杂菌”。
- 食谱页统一提醒：本食谱仅适用于已经由可靠方式确认身份的食用菌。烹饪不能使有毒蘑菇变得安全。不要仅凭本应用的识别结果决定是否食用。

**季节数据更透明**
- 图表显示覆盖年份、记录总数、最近一条记录和更新日期；样本太少时标“数据不足”。
- 历史观察数据反映过去记录的分布和季节性，不代表当前地点一定有蘑菇，也不能作为实时出菇预测。
- 生境和伴生树只帮你决定去哪里找，不能证明手上是哪种菌。

**菌记更可靠**
- 导入备份前先检查格式：文件不对、记录重复或格式错误都会说明，原有记录不会被改动。
- 删除记录时会说明会一起删除几张照片。

有任何疑问，就不要吃。
